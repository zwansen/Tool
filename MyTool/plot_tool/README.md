# 📊 交互式绘图工具

基于 Streamlit 的数据可视化工具，支持上传表格/文本文件，选择列进行交互式绘图；同时提供独立的列格式转换工具，用于经纬度与 UTC 时间格式互转。

## 功能特点

- **多格式支持**: CSV, Excel, TSV, TXT, LOG
- **语句型日志解析**: 支持 NMEA-like `$` 语句日志，可自动从 GGA/RMC 语句携带时间到无时间语句
- **通用文本解析也可继承 UTC**: 在按分隔符解析的通用模式下，同样可从附近的 `$xxGGA`/`$xxRMC` 语句继承 UTC 时间，方便给无时间字段的数据行绘图
- **自定义格式过滤**: 通用文本解析支持按自定义前缀（如 `[corr]`、`[corr] UTC_GAL`）筛选数据行；可进一步按前缀拆分为多个数据集，像多文件一样分别绘图，或在横坐标相同时合并到同一张图
- **多文件布局**: 多文件时可选"合并到一张图"或"每个文件单独绘图"
- **默认列名（不占用数据行）**: 通用文本解析可选择"使用默认列名"，列名格式为 `{文件名}_{前缀}_{n}`，多文件时自动去重，不再占用第一行数据
- **多分隔符拆分**: 支持"多个分隔符"（如同时按 `,` 和空格拆分）或"正则分隔符"（如 `[，,\\s]+`），处理一行中混用多种分隔符的情况
- **UTC 继承方向可选**: 从 `$xxGGA`/`$xxRMC` 继承 UTC 时，可选择"上方最近"、"下方最近"或"双向最近"
- **跨天 UTC 处理**: 检测到 UTC 跨天时，可输出 `HH:MM:SS(+offset)` 或累计秒数，方便连续绘图
- **无效 UTC 修复与定位状态标记**: 语句解析模式下，可修复 GGA/RMC 语句中时间为 `000000.000` 的无效 UTC（被有效时间夹在中间时线性插值填充），并新增 `utc_status` 列区分定位有效、不定位但 UTC 有效、不定位且 UTC 被填充、无法填充等状态
- **多种图表**: 折线图、散点图、柱状图、面积图、箱线图、直方图
- **交互式图表**: 使用 Plotly 实现缩放、悬停提示、图例切换等交互功能
- **数据过滤**: 支持按列值过滤数据后再绘图
- **导出功能**: 支持导出过滤后的数据和图表图片
- **列格式转换**: 独立的 `converter.py` 支持经纬度（ddmm.mmmm / dddmm.mmmm）与十进制度、UTC 时间（HHMMSS.SSS ↔ HH:MM:SS.SSS）互转

## 快速开始

### 1. 安装依赖

```bash
cd plot_tool
pip install -r requirements.txt
```

### 2. 启动应用

**主绘图工具：**

```bash
streamlit run app.py
```

**列格式转换工具：**

```bash
streamlit run converter.py
```

启动后，浏览器会自动打开 `http://localhost:8501`

### 文件大小限制

项目已配置 `.streamlit/config.toml`，单文件上传上限为 **4096 MB（4 GB）**。如需调整，可修改 `plot_tool/.streamlit/config.toml` 中的 `maxUploadSize` 值：

```toml
[server]
maxUploadSize = 4096
```

### 大文件解析性能建议

- 优先使用**单个分隔符**模式，解析速度最快；多分隔符/正则模式会逐行拆分，速度较慢。
- 如果只需要部分数据，可先使用 `跳过前 N 行` 或在文件外部预过滤，再上传。
- 勾选"启用自定义格式过滤"并精确填写前缀，可显著减少需要解析的数据行。
- 继承 UTC 时间时会扫描一次文件，若文件极大且不需要 UTC，可关闭该选项。
- 解析大文件时界面会显示"正在解析..."提示，请等待完成。

## 使用步骤

### 主绘图工具（`app.py`）

1. **上传文件**: 在左侧栏点击"Browse files"选择文件
2. **设置解析方式**:
   - **表格/普通文本**: 
     - 选择"表头设置"：使用文件自带表头，或使用默认列名（格式 `{文件名}_{前缀}_{n}`，不占用数据行）
     - 选择"分隔符模式"：单个分隔符、多个分隔符（每个字符都作为分隔符）或正则表达式分隔符
     - 若文件里混有 `$xxGGA`/`$xxRMC` 语句且数据行无时间，可勾选"从附近的 `$xxGGA`/`$xxRMC` 语句继承 UTC 时间"；继承方向可选"上方最近"、"下方最近"或"双向最近"
     - 跨天时可选输出格式：`HH:MM:SS(+offset)` 或累计秒数
   - **自定义格式过滤**: 若文件中混合了多种格式，可勾选"启用自定义格式过滤"，输入需要保留的数据行前缀（每行一个，如 `[corr]`、`[corr] UTC_GAL`）。当输入多个前缀时，可勾选"按前缀拆分为多个数据集"，每个前缀会成为一个独立数据集，可分别绘图或在横坐标相同时合并到同一张图
   - **NMEA-like `.log`**: 切换到"语句解析"模式，选择要提取的语句类型（如 `GNGGA`、`GNVTG`），支持从 GGA/RMC 携带时间到无时间语句；若 GGA/RMC 中存在不定位且 UTC 为 `000000.000` 的情况，可勾选"修复无效 UTC（000000.000）并标记定位状态"，被前后有效 UTC 夹住的无效时间会被线性插值填充，位于开头/末尾的则保持为空，并新增 `utc_status` 列用于按状态着色
3. **选择坐标轴与颜色列**: 在"坐标轴选择"中选择 X 轴和 Y 轴（Y 轴可多选）；如需按类别着色（例如用 `utc_status` 区分定位状态），在"颜色列"中选择对应列
4. **选择图表类型**: 折线图、散点图、柱状图等
5. **多文件布局** (多文件时): 选择"合并到一张图"或"每个文件单独绘图"
6. **设置图表标题和标签**
7. **(可选) 数据过滤**: 展开"高级: 数据过滤"按需筛选
8. **查看图表**: 图表将自动更新
9. **导出**: 下载 CSV 数据或 PNG 图片

### 列格式转换工具（`converter.py`）

1. **上传文件**: 在左侧栏选择 CSV / TXT / LOG / TSV / Excel 文件
2. **设置解析参数**: 选择分隔符、是否有表头、跳过前 N 行
3. **添加转换规则**:
   - **经纬度转换**: 把 NMEA 格式 `ddmm.mmmm`（纬度）或 `dddmm.mmmm`（经度）转换为十进制度；可自动识别或手动指定类型，可选半球列用于添加正负号
   - **UTC 转 HMS**: 把 `HHMMSS.SSS` 转换为 `HH:MM:SS.SSS`，固定保留 3 位小数
   - **HMS 转 UTC**: 把 `HH:MM:SS.SSS` 转换回 `HHMMSS.SSS`
4. **设置输出列名**: 默认为 `{源列}_converted`，可自定义；重复列名会被拦截
5. **查看转换结果**: 主界面会实时预览原始数据与转换后的数据
6. **导出结果**: 支持导出为 CSV、Excel 或 .log/.txt 文本文件；文本导出使用逗号分隔，原数据列在前，转换后的列追加在最后，并保留原始数值的小数位数

## 转换示例

### 经纬度

| 原始值 | 类型 | 转换结果 |
|--------|------|----------|
| `3100.0002267` | 纬度 | `31.0000037783`（十进制度） |
| `12103.1234` | 经度 | `13.7187233333`（十进制度） |

### UTC 时间

| 原始值 | 方向 | 转换结果 |
|--------|------|----------|
| `80510.8` | UTC → HMS | `08:05:10.800` |
| `080502.00` | UTC → HMS | `08:05:02.000` |
| `08:05:02.000` | HMS → UTC | `080502.000` |
